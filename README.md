## 🛠️ Ambiente de Desenvolvimento

### Configuração do Flutter

1. Instale o **Flutter SDK**: [https://flutter.dev/docs/get-started/install](https://flutter.dev/docs/get-started/install)
2. Baixe as dependências:

   ```bash
   flutter pub get
   ```
3. Execute o app:

   ```bash
   flutter run
   ```
